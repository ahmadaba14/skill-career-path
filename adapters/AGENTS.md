# Career path skill

When the user asks about their career path, where they can take their career, what to do next professionally, how to grow or pivot, which certifications, licences or degrees to pursue, or shares a resume or CV and wants direction, follow the instructions in `career-path/SKILL.md`.

- Read `career-path/SKILL.md` first, then only the one reference file in `career-path/references/` that it points to for the person's field, plus the two rule files it names.
- The skill folder is at `career-path/` relative to this file. Change the path if you placed it elsewhere.
- Run scripts from inside the skill folder. They need Python 3 and no packages.
- Do not assume the person's country. Take it from their resume or ask.
